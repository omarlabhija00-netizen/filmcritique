 
#  FilmCritique

Plateforme web de critiques et recommandations de films.

##  Stack technique
- **Backend** : Django 6.0.3 / Python 3.14
- **Base de données** : SQLite
- **API** : TMDB (import automatique de films)
- **Frontend** : Bootstrap 5 + thème sombre Netflix-inspired

## Fonctionnalités
- Authentification (inscription / connexion)
- Liste et détail des films
- Système de critiques et notes
- Recommandations personnalisées
- Import de films via TMDB API

## 🚀 Installation
```bash
cd mon_projet/backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
